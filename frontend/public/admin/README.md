# Admin Algeria Travel

Source HTML / CSS / JS du tableau de bord.

- Éditer ici : `client/admin/`
- Servi en ligne sur : `/admin/` (copie auto vers `frontend/public/admin/` au `npm start` / `npm run build`)

Login : `admin` / la clé `ADMIN_API_KEY` du backend (vérifiée par le serveur).

Section **Propriétaires** : comptes de l’espace partenaire (`/partenariat/`). Les biens, chambres, tarifs et
disponibilités de tous les propriétaires se gèrent via `../partenariat/index.html?admin=1` (même onglet, même session).
